One image that sums up the world's news of **Sunday 22 November 2026**, drawn as a
newspaper front page. The lead story is Iran's missile and drone strikes on US bases
in Bahrain as the Gulf war widens, with five more stories from the day across regions
and fields: a Russian cargo ship ablaze in the Baltic, Trump's push for a lasting
Iran deal, Russian missiles landing in Poland, Bolsonaro in intensive care, and a
cartel boss seized in Mexico.

## How it works

`main.ts` (Node 22, standard library only, no network) copies the pre-rendered
`entry.png` next to it into the output directory and verifies the copy is
byte-identical in size to the source.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` — a 1024x1024 JPEG (kept under the 1 MiB limit).
